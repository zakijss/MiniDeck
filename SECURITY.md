# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: on the Security
tab of the affected repository (an app's, or this one for the shared
library), choose "Report a vulnerability". For this repository that is
<https://github.com/zakijss/MiniDeck/security/advisories/new>. Don't open a
public issue for them.

Say what you found, the release or commit, and how to reproduce it. The reply
comes in the advisory's thread, and a fix ships in a new release.

A problem in Tailscale itself belongs with Tailscale: see
<https://tailscale.com/security>. If it affects MiniScale's build (for
example a fix that needs a newer pinned version), report it in
[MiniScale](https://github.com/zakijss/MiniScale) too.

## Supported versions

Only the latest release gets fixes.
